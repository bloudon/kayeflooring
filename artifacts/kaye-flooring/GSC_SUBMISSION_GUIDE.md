# Google Search Console — Sitemap & URL Submission Guide

## Sitemap URL
```
https://kayeflooring.com/sitemap.xml
```

---

## Step 1 — Resubmit the sitemap

1. Go to [Google Search Console](https://search.google.com/search-console)
2. Select the **kayeflooring.com** property
3. In the left sidebar click **Sitemaps**
4. If `sitemap.xml` is already listed, click the three-dot menu next to it and choose **Resubmit**
5. If it is not listed, paste `sitemap.xml` into the "Add a new sitemap" field and click **Submit**
6. Status should change to **Success** — this confirms Google has received the updated sitemap including the Pasco County page

---

## Step 2 — Request direct indexing for the Pasco County page

This tells Google to crawl the page right now rather than waiting for its normal schedule.

1. In Search Console, paste this URL into the top search bar and press Enter:
   ```
   https://kayeflooring.com/pasco-county-flooring
   ```
2. Click **Request Indexing**
3. Google will crawl the page within a few days

Repeat for any other new pages you want indexed quickly:
- `https://kayeflooring.com/citrus-county-flooring`
- `https://kayeflooring.com/hernando-county-flooring`
